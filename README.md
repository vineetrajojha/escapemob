# Escape Mob
================

## What the project does
Escape Mob is a web application built using Next.js, providing a platform for users to explore and interact with various services and projects. The application features a modern design, responsive layout, and engaging user experience.

## Why the project is useful
Key features and benefits of Escape Mob include:

* **Modern Design**: A sleek and responsive design that adapts to various devices and screen sizes.
* **Service Showcase**: A platform to showcase various services, including branding, creative, media, social, and website development.
* **Project Portfolio**: A showcase of completed projects, featuring images, videos, and descriptions.
* **Interactive Components**: Engaging components, such as a custom cursor, tilt card, and theme toggle, enhance the user experience.

## How users can get started
To get started with Escape Mob, follow these steps:

1. **Clone the repository**: Clone the repository using `git clone https://github.com/vineetrajojha/escapemob.git`.
2. **Install dependencies**: Install the required dependencies using `npm install` or `yarn install`.
3. **Start the application**: Start the application using `npm run dev` or `yarn dev`.
4. **Access the application**: Access the application at `http://localhost:3000`.

### Example Usage
```bash
# Clone the repository
git clone https://github.com/vineetrajojha/escapemob.git

# Install dependencies
npm install

# Start the application
npm run dev

# Access the application
http://localhost:3000
```
